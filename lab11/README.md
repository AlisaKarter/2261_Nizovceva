Глобальные и статические массивы располагаются в одной области памяти.  
Локальные массивы на стеке располагаются в другой области.

Время жизни:  
Глобальные — создаются при запуске программы, удаляются при завершении  
Статические локальные — создаются при первом вызове функции, удаляются при завершении программы  
Локальные на стеке — создаются при входе в блок, удаляются при выходе  
В куче — создаются и удаляются по запросу.

*Рассмотрите следующую программу. Выполните ее трансляцию, используя  компилятор g++ без

```
#include <iostream>
double &choose(double &a, bool flg) {
    double pi = 3.14;
    double &r = flg ? pi : a;
    return r;
}

int main(void)
{
    double a = 2.7;
    double &pi = choose(a, true);
    std::cout << pi << std::endl;
    double &e = choose(a, false);
    std::cout << e << std::endl;
    std::cout << pi << std::endl;
    return 0;
```

В main переменная pi (ссылка) получает эту ссылку  
Выводится 3.14  

Второй вызов choose(a, false):  
flg = false, поэтому r ссылается на a
